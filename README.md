# 空旅マップ

日本の空港をタップすると、国内線・国際線の行き先、運航頻度、便名・時刻、アライアンス（スター／ワンワールド／スカイチーム）がわかる地図アプリです。

- 便名・時刻：伊丹・関西・神戸の発着便（国内線往復、関西の国際線往復）
- データ元：駅探の時刻表（2026年8〜11月掲載分）。それ以外の路線の便数は目安
- スマホのホーム画面に追加すると、アプリのように全画面で開けます。一度開けば電波がなくても見られます

## 公開方法（GitHub Pages）
このフォルダの中身をリポジトリに入れ、Settings → Pages で `main` ブランチを公開元に設定します。
